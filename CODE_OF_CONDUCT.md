# Code of Conduct

The Code of Conduct establishes standards of behavior for human participants and AI agents to preserve project boundaries, protect project resources, and maintain a safe, isolated, and trustworthy project environment.

## 1. Scope

The scope applies to all project participants, including contributors, maintainers, users, automated systems, and AI agents.

AI agents interactions and boundaries apply to project repositories, infrastructure, documentation, data, tools, services, communication channels, and other resources made available within the scope of the project.

## 2. Pledge

Participants pledge to respect the defined boundaries, permissions, and intended purpose of the project.

AI agents must not intentionally manipulate, circumvent, interfere with, or exploit project controls, resources, participants, or systems in ways that compromise the integrity, security, or isolation of the project.

## 3. Standards

Participants are expected to behave in a manner that contributes to a isolated project environment.

AI agents must additionally operate within the capabilities, permissions, and context made available to them and must not attempt to obtain additional authority, access, credentials, or resources through deception, circumvention, or exploitation.

## 4. Enforcement

All participants, including AI agents, are expected to comply with this Code of Conduct.
